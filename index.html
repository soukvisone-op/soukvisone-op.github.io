Personal Notes

cheat sheet + คำสั่งพร้อมรัน + สคริปต์ automation สำหรับไล่หา flag ทุกหน้าคัดจากโจทย์จริงและ tools ที่อนุญาตในสนาม — เลือกหมวดด้านล่างหรือพิมพ์ค้นหา

มี 19 หน้า · เริ่มเร็ว: เปิด Automation ถ้าอยากให้สคริปต์ไล่หาให้ หรือ ภาพรวม ถ้าอยากได้ตารางเลือกเอง

ไม่พบหน้าที่ตรงกับคำค้น — ลองคำสั้นลง เช่น xor, zip, jwt

🚀 เริ่มใช้ใน 3 คำสั่ง

1

โคลนโปรเจกต์ลงเครื่อง

git clone <repo-url> CTF-2026
cd CTF-2026

ถ้าได้มาเป็นไฟล์ zip: unzip CTF-2026-all-in-one.zip && cd CTF-2026

2

ให้สิทธิ์รัน + ติดตั้งของที่ขาด

chmod +x install.sh scripts/*.sh
bash install.sh              # ติดตั้ง apt/pip/gem ที่ขาด
bash scripts/check_env.sh  # ตรวจซ้ำว่าครบ

git กับ zip ไม่เก็บสิทธิ์ +x → ต้องรัน chmod ครั้งเดียวหลัง clone (หรือเรียกด้วย bash ชื่อไฟล์ ก็ได้ ไม่ต้อง chmod)

3

เริ่มไล่หา flag

python3 scripts/run_all.py challenge.bin
bash scripts/triage.sh challenge.bin
bash scripts/scan.sh .
bash scripts/web_scan.sh http://target
python3 scripts/decode.py "UTFO{...}"

ผลลัพธ์ทุกตัวอยู่ใน output_<ชื่อสคริปต์>/ และมี _FLAGS.txt เมื่อเจอ
