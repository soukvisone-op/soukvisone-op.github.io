========================================================
  START HERE — 3 ขั้นตอนขึ้น GitHub Pages
========================================================

โฟลเดอร์นี้ = สิ่งที่ต้องอยู่ใน root ของ repo
มี index.html อยู่แล้ว → อัปโหลดปุ๊บเปิดเว็บได้เลย


--------------------------------------------------------
ขั้นที่ 1: อัปโหลด (ไม่ต้องลบของเก่า GitHub เขียนทับให้)
--------------------------------------------------------
1. เปิด  github.com/<username>/soukvisone.github.io
2. กด  Add file  →  Upload files
3. เปิดโฟลเดอร์นี้ใน Explorer
   → กด Ctrl+A (เลือกทั้งไฟล์และโฟลเดอร์)
   → ลากมาวางในกรอบของ GitHub
4. รอจนรายการขึ้นครบ (ประมาณ 57 ไฟล์)
5. กด  Commit changes

ห้าม: ลากไฟล์ .zip ขึ้นไป (GitHub ไม่แตกให้)


--------------------------------------------------------
ขั้นที่ 2: เปิด Pages (ทำครั้งเดียว)
--------------------------------------------------------
Settings → Pages
   Source : Deploy from a branch
   Branch : main
   Folder : / (root)          ← ต้องเป็น root
   → Save

รอ 1-2 นาที


--------------------------------------------------------
ขั้นที่ 3: เปิดเว็บ
--------------------------------------------------------
ถ้า repo ชื่อ  soukvisone.github.io
   → https://soukvisone.github.io/

ถ้า repo ชื่ออย่างอื่น เช่น notes
   → https://soukvisone.github.io/notes/

กด Ctrl+F5 ถ้ายังเห็นของเก่า


--------------------------------------------------------
ถ้าไม่ขึ้น (404)
--------------------------------------------------------
[ ] ยังไม่กด Save ในหน้า Pages
[ ] เลือก Folder ไม่ใช่ / (root)
[ ] อัปโหลดเป็น .zip ไม่ได้แตกไฟล์
[ ] ไม่มี index.html อยู่ที่ root
[ ] ลืมโฟลเดอร์ assets/ (เว็บจะไม่มีสีสัน)


--------------------------------------------------------
หน้าที่มีในชุดนี้
--------------------------------------------------------
index.html          หน้าแรก (ค้นหา + การ์ดทุกหมวด)
QUICKCARD.html      การ์ดคำสั่งลัด 1 หน้า (ปริ๊นได้)
overview.html       ตาราง “ได้อะไรมา → เปิดหน้าไหน”
RANKING.html        อันดับงานที่พบบ่อย 1-2-3-4 ตามหมวด
FILETYPES.html      ไฟล์/นามสกุล → ใช้โปรแกรมอะไร
APPROVED.html       ซอฟต์แวร์ที่อนุญาต / ห้าม
tools.html          ดัชนีคำสั่ง (Command Index)
Workflow/           สคริปต์ช่วยทำงาน + วิธีใช้
Crypto/ Forensics/ Web/ Network/ Reverse/ OSINT/ Misc/
                    หน้าเนื้อหา (.html + .md)


--------------------------------------------------------
โฟลเดอร์ scripts/ (รันบนเครื่อง ไม่ใช่บนเว็บ)
--------------------------------------------------------
run_all.py      ตัวสั่งงานเดียว
triage.sh       ตรวจไฟล์เดียว
scan.sh         ไล่หาทั้งโฟลเดอร์
web_scan.sh     สแกนเว็บ
decode.py       ถอดรหัสข้อความ
check_env.sh    ตรวจว่ามีโปรแกรมครบไหม

เจอคำตอบจะขึ้นกรอบเขียวให้เห็นทันที ไม่ต้องเปิดไฟล์ผลลัพธ์


--------------------------------------------------------
ไฟล์อื่น ๆ
--------------------------------------------------------
extra.zip         ชุดสคริปต์รุ่นเก่า 71 ไฟล์ (แตกเมื่อต้องใช้)
requirements.txt  รายการโปรแกรม + วิธีติดตั้ง
install.sh        ติดตั้งของที่ขาด + chmod + build หน้าเว็บ
build.py          สร้าง .html จาก .md
DEPLOY.md         คู่มือ deploy ฉบับเต็ม
MANIFEST.txt      รายชื่อไฟล์ทั้งหมด (เช็กว่าอัปครบ)


--------------------------------------------------------
อยากแก้เนื้อหา
--------------------------------------------------------
1. แก้ไฟล์ .md ที่ต้องการ
2. cd โฟลเดอร์นี้ แล้วรัน:  python3 build.py
3. อัปโหลด .html ที่เปลี่ยนใหม่

หมายเหตุ: อย่าแก้ .html มือเปล่า เพราะ build.py จะเขียนทับ
